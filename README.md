# Semanário de Aulas | Colégio Gênesis Life

Protótipo com login demonstrativo e registros salvos no navegador.

| Para mudar | Arquivo |
| --- | --- |
| Telas, campos e textos da interface | `index.html` |
| Cores do aplicativo, animações e impressão A4 | `css/app.css` |
| Tipografia, espaçamentos e estilos compartilhados | `css/base.css` |
| Turmas, disciplinas, dados de exemplo, filtros e salvamento | `js/app.js` |
| Logo | `assets/logo.png` |

`js/bootstrap.js` carrega o aplicativo e `js/vendor/` contém as dependências do protótipo.

Para testar localmente, execute `python -m http.server 8000` na raiz e acesse
[localhost:8000](http://localhost:8000). O GitHub Pages pode servir a raiz do repositório sem etapa de compilação.
